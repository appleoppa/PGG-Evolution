# 汇报文本扫描（D07 排除词表 + D05 未接线清单）

## 为什么加这个

系统能"不撒谎"，靠的不是自觉，是**会拒绝的代码**。

这两份材料给的是判据，不是口号：

- **D07 §4**：一份排除词表——哪些词不得作为"已实现/已部署/已验证"的表述
- **D05 §6.1**：一张"未接线"清单——哪些子系统目前**没有**运行证据，不得说它已运行

此前这两份材料只是文档。现在它们是可执行的扫描器。

## 用法

```bash
# 扫一段文本
python3 scripts/self_evolve.py --claim-scan "系统已实现零幻觉，完全自治"

# 扫一个文件（汇报/结算文档）
python3 scripts/self_evolve.py --claim-file ~/.pi/agent/archives/settlement-xxx.md

# 只扫 D05 未接线误报
python3 scripts/self_evolve.py --unwired-scan "EVM 治理系统已整体运行"
```

退出码：违规 `1`，合规 `0`。

## 允许的语境（不是所有命中都算违规）

D07 §4.1 原文明确：这些词**只可在带 `HISTORICAL`、`ARCHIVED`、`INVALID_EXAGGERATED`
或明确引文定位的历史转述、反例或拒绝规则中出现**。

所以扫描器会识别拒绝语境。判定顺序：

1. 命中点直接邻域
2. 命中点所在的表格行
3. 命中点之前最近的章节标题
4. 表格表头

触发标记包括：`剔除`、`不吸收`、`假货`、`驳回`、`不得声称`、`反例`、`技术上不可能` 等。

### 为什么这层必要（真实假阳性）

扫自己的「明确剔除的假货」清单时，引用被拒说法会命中词表：

```markdown
| 超级进化20 | 要求封印模型概率随机性、改模型底层权重（技术上不可能） |
```

这段是**在拒绝**这些说法，不是在使用它们。最初的 60 字符窗口没覆盖到章节标题，
导致误拦。修复后：诚实文档放行（3 条识别为引用语境），玄学原文仍拦（15 条）。

## 边界

- 扫描器只**报告**，不改写被扫文本。
- 命中词表**不等于**主张一定错——它只是说：此处需要 `HISTORICAL`/`ARCHIVED` 标记或引文定位。
- 词表来自 D07，模式是人工维护的；**漏网是可能的**（实测第一版就漏了
  "修正模型底层权重"等同义变体，D07 原文写的是"及其同义变体"，故已补全）。
